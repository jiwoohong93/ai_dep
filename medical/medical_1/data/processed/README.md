# Processed data

`data_preprocessing/data_preprocessing.ipynb` 의 출력이 저장되는 폴더입니다. 데이터는 저장소에 포함되어 있지 않습니다.

- `df_merge_train_diagnosis_18_eng.csv`: 학습 데이터
- `df_merge_test_diagnosis_18_eng.csv`: 테스트 데이터
- `df_merge_all_diagnosis_18_eng.csv`: 분할 전 전체 데이터

`_eng` 가 없는 같은 이름의 `.csv` / `.xlsx` 는 국문 컬럼명 버전입니다. 학습과 추론 스크립트는 영문 컬럼명 파일을 사용합니다.
