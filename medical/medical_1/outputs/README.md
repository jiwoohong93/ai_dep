# Outputs

스크립트 실행 결과가 저장되는 폴더입니다.

- `train/`: `train.py` 의 그림과 리포트
- `inference/single/`: `inference_single.py` 의 단일 환자 예측 결과와 SHAP
- `inference/test/`: `inference_test.py` 의 test set 평가 결과와 SHAP
- `posthoc/`: `posthoc_analysis.py` 의 subgroup 지표와 SHAP
- `fairness/`: `fairness_eval.py` 의 개별공정성 지표
- `comparison/`: `compare_variants.py` 의 방식별 비교 결과
