# Retain 오류 rule별 분해 (교차 오염 분석)

## 종합 해석 (교차 오염 가설 판정)

**판정: retain 피해는 무차별이 아니라 구조적** — 세 층위로 집중된다.

1. **1순위 — 자기 경계 과잉 이동 (`over:자기자신`)**: 대부분 케이스에서 오류의 최대 지분.
   편집이 θ′에서 멈추지 않고 안전존까지 밀어붙인 것 (case 1은 오류의 95~98%가 이것).
   → 경계 정밀도 문제 = 보존 샘플(안전존)의 key가 플립존 key와 충분히 분리되지 않는 문제.
2. **2순위 — 의미적 이웃 rule로의 교차 오염 (`over:/lost:교차`)**:
   - 자기자본비율 편집 → **단순기본자본비율** 과잉 거절 52~62% (둘 다 "자본/자산"형 비율)
   - 공제후자본양수 편집 → 단순기본(45~58%)·유동·부채비율로 확산
   - 은행 rule 편집(6·8, ROME/EMMET) → **유동비율 판정 상실** (`lost:유동비율` 3,390 =
     해당 decisive 행 전멸로 추정) + multi_fail 과반
   → locate에서 본 "얽힌 표현"이 편집 피해 경로로 실증됨.
3. **MEMIT의 낮은 피해는 절반만 미덕**: case 6·8의 오류 ~0은 efficacy도 ~0이었기 때문
   (편집 무효과의 부산물). 진짜 균형은 case 1·3에서만 성립.

부수 산출물: 전 런 `predictions.csv` 저장됨 — 이후 행 단위 분석은 GPU 불필요.

생성: `src/editing/analyze_retain.py` — 각 런의 retain 오류를 원인 rule로 귀속.
`lost:X` = rule X 판정 상실(라벨0→통과 오판) / `over:X` = X 경계 근처 과잉 거절(라벨1→탈락 오판)
