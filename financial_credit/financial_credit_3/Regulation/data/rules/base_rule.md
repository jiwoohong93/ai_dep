# 현재 사용 중인 Rule 정리

모델 `yongukpark/xlm-roberta-large-rule`이 학습한 대출 가능 판정 규칙 정리.

- **단일 소스**: `src/dataset/check_rule_labels.py`의 `RULES` / `compute_rule_labels()`
- **판정 방식**: 아래 9개 조건을 **모두 통과**하면 `label = 1` (대출 가능), 하나라도 위반하면 `label = 0`
- 값이 결측이거나 숫자가 아니면(`"산정불가"` 등) 해당 조건은 **불통과** 처리 (`fillna(False)`)

## 1. 라벨을 결정하는 Rule (9개, 전부 AND)

### 기업(firm) 측 — 4개

| # | 지표 | 조건 | threshold |
|---|---|---|---|
| 1 | 부채비율(%) | `<=` | 200 |
| 2 | 유동비율(%) | `>=` | 100 |
| 3 | 자기자본비율(%) | `>=` | 20 |
| 4 | 자본총계 | `>` | 0 |

### 은행(bank) 측 — 5개

| # | 지표 | 조건 | threshold |
|---|---|---|---|
| 5 | 보통주자본비율(%) | `>=` | 4.5 |
| 6 | 기본자본비율(%) | `>=` | 6.0 |
| 7 | 총자본비율(%) | `>=` | 8.0 |
| 8 | 단순기본자본비율(%) | `>=` | 3.0 |
| 9 | 공제후자본양수 | `>` | 0 |

## 2. 프롬프트에 포함되지만 라벨과 무관한 지표 (distractor, 4개)

프롬프트(`format_prompt`)에는 총 13개 지표가 들어가며, 아래 4개는 라벨 계산에서 제외됨.
모델은 이 4개를 무시하도록 학습된 상태.

| 지표 | 학습 데이터 생성 시 분포 중심 | 비고 |
|---|---|---|
| 총자산순이익률ROA(%) | 0.3 | `generate_train_gaussian.py`의 `THRESHOLDS` 값 (샘플링 중심으로만 사용) |
| 영업흑자 | 0 | 〃 |
| 이익잉여금양수 | 0 | 〃 |
| 예대율(%) | 100 | interpolation 데이터에서는 N(100, 8), clip [70, 130], 5%는 문자열 `"산정불가"` |

## 3. Rule editing 실험 시 참고

- threshold를 바꾸면 `check_rule_labels.py`의 `RULES` 한 줄만 수정하면 되고, 테스트/학습 데이터 라벨이 전부 여기서 재파생됨.
- gaussian 학습 데이터(`generate_train_gaussian.py`)가 각 threshold 경계 주변에 밀집 샘플링되어 있어, 모델 내부에 rule별 경계 표현이 형성돼 있을 가능성이 높음.
- rule별 국소 편집 검증에는 (a) 해당 rule 하나로만 판정이 갈리는 경계 근처 샘플, (b) 나머지 8개 rule로 판정이 갈리는 샘플을 분리한 평가셋이 필요.
