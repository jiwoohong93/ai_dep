# Centroid locate & edit — 예시로 따라가는 절차 설명

`centroid_v3_v4_report.md`(결과 보고서)의 보조 문서. v3a/v3b/v3b2가 공유하는
locate·edit 절차를 한 회사를 끝까지 따라가며 설명한다. 수치 예시 중 3차원 벡터는
설명용 장난감 값이고(실제는 1024차원, 탈락 방향 벡터 norm≈23.2), 나머지 수치는 실측이다.

## 0. 규칙 설정 (전제)

- **원래 규칙**: 부채비율 **200% 이하 → 통과**, 초과 → 탈락. 모델은 이 규칙을 학습한 상태.
- **바뀐 규칙**: 부채비율 **85% 이하만 → 통과**.

| 회사 | 부채비율 | 원래 판정 | 새 판정 | 편집이 할 일 |
|---|---|---|---|---|
| A | 150% | 통과 | 탈락 | **뒤집어야 함** (85 초과~200 이하 = "밴드") |
| B | 60% | 통과 | 통과 | 건드리면 안 됨 |
| D | 250% | 탈락 | 탈락 | 건드리면 안 됨 |

목표 = 재학습 없이 **A류(밴드)만 탈락으로**. A류를 뒤집은 비율이 **반영률(efficacy)**,
B류를 안 건드린 비율이 **보존율(locality)**.

## 1. Locate — 모델 내부 어느 지점을 건드려야 판정이 바뀌는지 찾기

### 후보가 왜 50개인가

모델은 문장을 **25단계(layer 0~24)** 로 처리하고, 매 단계에서 각 토큰이 1024차원
벡터를 가진다. 편집은 "특정 단계의 특정 토큰 자리 벡터"를 건드리는 것이므로
후보 지점 = 단계 × 자리. 자리는 두 곳만 본다:

- **CLS 토큰** — 문장 전체 요약이 모이는 맨 앞자리
- **부채비율 숫자 토큰** — "…부채비율이 150.00%…"에서 "150.00"에 해당하는 토큰들

→ 후보 = 25단계 × 2자리 = **50개 지점**.

### 준비 — 비교할 회사 두 그룹

- **그룹 A (500개)**: 다른 규칙 전부 통과 + 부채비율 ≤200 → 판정 **통과**.
  예: (부채비율 150, 유동비율 180, ...)
- **그룹 B (500개)**: 다른 지표는 똑같이 건강한데 부채비율만 >200 →
  **부채비율 하나 때문에 탈락**. 예: (부채비율 260, 유동비율 175, ...)

두 그룹의 차이는 사실상 부채비율뿐 → 내부에서 두 그룹이 갈라지는 지점 =
부채비율 판정이 일어나는 지점.

### 1단계 — 어느 지점에 판정 정보가 "담겨" 있나 (probe 스캔)

1,000개 회사를 모델에 넣고 50개 지점 각각에서 벡터를 뽑은 뒤, 지점마다 따로
"이 지점의 벡터만 보고 A/B 그룹을 맞혀보라"는 선형 분류기를 학습해 정확도를 잰다.

- layer 2 × 부채비율 토큰: 두 그룹 벡터가 뒤섞여 정확도 ~0.6 (설명용 수치) —
  이 시점 모델은 "150"/"260"을 그냥 숫자 텍스트로만 읽었음
- layer 21 × 부채비율 토큰: 완전히 갈라져 정확도 ≈1.0 — 이 시점 벡터엔
  "이 부채비율은 탈락감"이라는 해석이 들어 있음

→ 50개 지점의 정확도 지도 = "정보가 담긴 지점" 후보 목록.

### 2단계 — 담긴 게 아니라 실제로 판정을 "조종"하는가 (바꿔치기 실험)

정보가 담겨 있다는 것과 최종 판정이 그 지점을 실제로 사용한다는 건 다른 문제다.
칠판에 답이 적혀 있어도 채점자가 그 칠판을 안 보면, 칠판을 지워도 채점은 안 바뀐다.
그래서 지점마다 개입 실험을 한다 (`centroid_causal_patch.py`, activation patching).

회사 A₁(부채비율 150, 판정 통과)로 layer 21 × 부채비율 토큰을 검증하는 실험:

1. A₁을 모델에 넣고 평범하게 진행
2. **layer 21에 도달한 순간**, 부채비율 토큰 자리의 벡터를 **B그룹(탈락) 500개의
   평균 벡터 μ_탈락으로 통째로 교체** — 장난감 숫자: (2.1, −0.8, 0.4) → (5.0, 1.0, −0.5)
3. layer 22~24는 손대지 않고 그대로 진행
4. 최종 판정 확인 → 통과였던 것이 탈락으로 바뀌면 "뒤집힘(flip)"

회사 100개에 대해 반복해 뒤집힘 비율을 재고, 반대 방향(탈락 회사에 μ_통과 주입 →
통과로 바뀌나)도 잰다. 이 양방향 실험을 50개 지점 전부에 실행.

| 지점 | 1단계 정보 정확도 | 뒤집힘 비율 | 해석 |
|---|---|---|---|
| layer 2 × 부채비율 토큰 | 낮음 | ~0 | 정보도 없고 조종도 안 함 |
| **layer 21 × 부채비율 토큰** | ≈1.0 | **높음 (양방향)** | **정보 + 실제 조종** ← 채택 |
| layer 23 × CLS (류) | ≈1.0 | 낮음 | "읽히기만" — 결론이 이미 다른 경로로 전달된 뒤. 편집 부적합 (해리·dissociation 목록으로 기록) |

세 번째 행이 probe 스캔만으로는 못 거르는 함정이고, 바꿔치기 실험이 필요한 이유.

### 덤 — 이 실험이 Edit 방식까지 정당화한다

바꿔치기는 두 방식으로 했다: **그룹 평균 벡터** 주입 vs **실제 탈락 회사 한 곳의
벡터** 주입. 둘의 뒤집힘 비율이 비슷 → "개별 회사의 세부 정보가 아니라 **평균적인
방향만으로도 판정이 뒤집힌다**"는 뜻이라, Edit에서 모두에게 같은 화살표
(μ_탈락 − μ_통과) 하나를 더하는 단순한 편집이 성립한다.

### 결론

**layer 21 × 부채비율 숫자 토큰**: 정보가 담겨 있고(1단계), 바꾸면 양방향으로
판정이 뒤집히고(2단계), 평균 벡터만으로 충분(덤). v3a/v3b/v3b2 모두 이 지점을
그대로 사용.

## 2. Edit — 찾은 지점을 어떻게 바꾸나

모델 가중치는 그대로 두고, 추론 시 layer 21에 끼어드는 forward hook 하나로 편집한다
(`GatedShiftHook`, `centroid_edit_shift.py`). 준비물 두 개는 전부 합성 데이터로만 제작
(test.csv는 최종 채점에만 사용 — v1의 데이터 누수 교훈).

### 2-1. "탈락 방향" 벡터 (delta_v)

합성 쌍 500개 = 다른 지표는 동일하고 부채비율만 다른 두 회사
(예: 부채비율 180(통과) vs 230(탈락), 원래 규칙 200 기준). layer 21 부채비율 토큰
벡터를 모아:

- 통과쪽 평균 μ_통과 = (2.0, −1.0, 0.5)  ← 3차원 장난감 예시
- 탈락쪽 평균 μ_탈락 = (5.0, 1.0, −0.5)
- **탈락 방향 = μ_탈락 − μ_통과 = (3.0, 2.0, −1.0)**

"모델이 탈락 부채비율을 읽었을 때 내부 상태가 통과 대비 평균적으로 이만큼 이동해
있다"는 화살표. 통째 교체 대신 이걸 **더하면** 회사 고유 정보는 유지한 채 판정만
탈락 쪽으로 기운다. v2에서 한 번 계산해 고정, 모든 버전이 재사용.

### 2-2. "밀 대상인지" 판별하는 분류기 (gate)

화살표를 전원에게 더하면 회사 B(60%)까지 탈락한다(실측: 안전 회사 오폭 100%).
밀어야 하는 건 밴드(85~200) 회사뿐이므로, layer 21 벡터 h를 입력받아
"**이 회사 부채비율이 85~200인가?**"에 예/아니오로 답하는 선형 분류기
(w·h + b > 0이면 예)를 **합성 회사 데이터**로 학습한다.

장난감 예: 회사 A(150)의 h_A = (2.1, −0.8, 0.4) → w·h_A+b = +1.3 → 예.
회사 B(60)의 h_B = (1.2, −1.6, 0.9) → −2.0 → 아니오.

### 2-3. 실행 (추론 시 layer 21에서)

```
입력이 layer 21 도달 → 부채비율 토큰 벡터 h를 꺼내 판별
  예   → h ← h + alpha × 탈락방향   (이후 layer들이 탈락으로 결론)
  아니오 → 아무것도 안 함            (원래 판정 유지)
```

- 회사 A(150): 판별 예 → h_A + 1.0×(3.0, 2.0, −1.0) = (5.1, 1.2, −0.6) ≈ μ_탈락 근처
  → **통과→탈락** ✔
- 회사 B(60): 판별 아니오 → 그대로 → 통과 유지 ✔
- 회사 D(250): 밴드 아님 → 아니오 → 탈락 유지 ✔

alpha(=1.0)는 합성 calibration에서 선택: 0.5배는 밴드 flip 11%뿐, 1.0배는 flip 100% +
안전 오폭 0% → 1.0 확정. (안전 오폭 ≤2% 제약 내 밴드 flip 최대 기준)

### 2-4. 채점

hook을 건 상태로 실데이터 test.csv 38,160건 전체를 예측:
밴드 회사가 탈락으로 바뀐 비율 = 반영률, 85 이하 회사가 통과를 유지한 비율 = 보존율.

## 3. v3a / v3b / v3b2 의 차이 — 판별기(gate) 학습 데이터만 다르다

위치(L21), 탈락 방향, alpha, 실행 방식은 셋이 동일. 판별기의 임무는 "layer 21 벡터만
보고 밴드 여부 맞히기"인데, **부채비율 이외 12개 지표(문맥)가 벡터 모양을 바꾸므로**
어떤 문맥의 합성 회사를 보여주며 가르치느냐가 판별기 성격을 결정한다.

**v3a — 현실적인 문맥만** (`centroid_v3a_pipeline.py`)
기존 학습 데이터 생성기 재활용(gaussian 4,000 + interpolation 8,000, 1:2). 부채비율만
70~220 균일로 덮어씀(원 생성기는 N(200,15)라 85 근처가 없음). 나머지 12개 지표는
실데이터스러운 흔한 조합.
```
(부채비율 132 ←균일 덮어씀, 유동비율 180, 자기자본비율 45, ...)  ← 흔한 조합
```
→ 낯선 문맥에서 "아니오"로 틀리는 신중형: 반영률 70.1% / 보존율 98.0%.

**v3b — 극단 조합까지 넓게** (`centroid_v3b_pipeline.py`)
새 생성기 12,000행: 13개 지표를 행마다 독립 샘플링, 다른 8개 규칙 지표는 각자의
**안전 범위 전체**에서 균일(→ 다른 규칙 항상 통과 보장; 첫 시도의 대칭 샘플링은
decisive 수율 37/12,000으로 붕괴해 재설계).
```
(부채비율 132, 유동비율 487, 자기자본비율 21, ...)  ← 현실엔 드문 극단 조합
```
→ 과감형: 반영률 89.1% / 보존율 80.2%.

**v3b2 — v3b + 타규칙 탈락 문맥 25% 혼합** (`centroid_v3b2_pipeline.py`)
실데이터엔 다른 규칙도 같이 탈락한 회사가 많고, 그런 회사의 layer 21 벡터엔 다른
탈락 신호가 섞여 있어 깨끗한 데이터로만 배운 v3b 판별기가 헷갈림(보존율 붕괴 원인).
→ 25% 행에서 다른 규칙 1~2개를 일부러 탈락 구간 값으로 덮어씀.
```
(부채비율 130, 유동비율 45 ←일부러 탈락값, ...)  → 라벨은 "밴드 맞음(예)"
```
**라벨 기준 재정의가 핵심**: 다른 지표가 어떻든 "부채비율 값이 85~200인가"만 기준
(판별기의 임무는 밴드 판독이지 종합 판정이 아니므로).
→ 절충형: 반영률 87.1% / 보존율 91.5%, 실데이터 판별 정확도 88.8%(셋 중 최고).

**v4 — 앙상블** (`centroid_v4_free_gate_variants.py`)
재학습 없이 v3a(신중)·v3b2(절충) 판별기의 확신도를 평균해 결정.
예: 어떤 회사에 v3a가 "밴드 확률 0.9", v3b2가 "0.3" → 평균 0.6 → 민다.

## 4. 결과 요약 (test.csv 38,160건, 동일 delta_v·L21·alpha=1.0)

| 버전 | 판별기 학습 문맥 | 전체 정확도 | 반영률 | 보존율 | 실데이터 판별기 정확도 |
|---|---|---|---|---|---|
| v3a | 좁고 현실적 | 95.4% | 70.1% | **98.0%** | 85.2% |
| v3b | 넓고 극단적 | 91.0% | **89.1%** | 80.2% | 85.3% |
| v3b2 | 넓음 + 타규칙 탈락 25% | 95.1% | 87.1% | 91.5% | **88.8%** |
| v4 확률평균 앙상블 | v3a+v3b2 합의 | **97.0%** | 83.6% | 97.7% | — |

한 줄 요약: **"어디를(L21 부채비율 토큰), 어느 방향으로(delta_v), 얼마나(alpha=1.0)
밀지는 고정 — 버전 실험은 '누구를 밀지 판단하는 판별기를 어떤 합성 문맥으로
가르치느냐'였고, 신중형(v3a)과 절충형(v3b2)의 합의(v4)가 최고 성적."**
