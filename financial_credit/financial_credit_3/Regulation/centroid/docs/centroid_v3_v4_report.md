# Regulation centroid 편집 실험 보고서 (v3/v4)

부채비율 규칙(≤200% 통과 → ≤85% 통과로 강화) 편집 실험 중, 최종적으로 채택 가능한
v3~v4 단계 기록. 모델 재학습 없이 모델 내부 표현을 살짝 밀어주는 방식으로 규칙을
바꾸는 게 목표였고, 이 문서는 그 과정과 결과를 정리한다.

> locate·edit 절차를 처음 보는 사람용 상세 설명(예시 회사를 끝까지 따라가는
> walkthrough)은 [centroid_locate_edit_walkthrough.md](centroid_locate_edit_walkthrough.md) 참고.

## 0. 용어 (쉬운 말로)

이 실험엔 비슷해 보이지만 서로 다른 두 부품이 나온다 — 헷갈리기 쉬워서 먼저 정리한다.

| 기술 용어 | 쉬운 표현 | 설명 |
|---|---|---|
| **centroid / delta_v** | **판정 방향(벡터)** | "통과 그룹"과 "탈락 그룹" 각각의 평균 내부 표현을 구해서 뺀 것. "이 방향으로 밀면 판정이 바뀐다"는 방향을 알려줌. 모델 재학습 없이 이 방향으로 살짝 밀어주는 게 편집의 핵심 |
| **gate(게이트)** | **판별기** | "이 사람한테 방금 그 판정 방향을 적용해야 하는가"를 판단하는 작은 분류기. 판정 방향과는 별개 부품 — 판정 방향은 "어디로 밀지", 판별기는 "누구를 밀지"를 정함 |
| **locate(로케이트)** | **위치 탐색** | 모델의 24개 처리 단계(layer) 중 어디에서 판정 방향을 적용해야 효과가 있는지 찾는 단계 |
| **efficacy(효능)** | **반영률** | 바뀌어야 할 대상(부채비율 85~200% 구간) 중 실제로 편집이 적용된 비율 |

| **locality(지역성)** | **보존율** | 안 바뀌어야 할 대상(부채비율 85% 이하 등) 중 실제로 안 바뀐 비율 — 높을수록 부작용이 적다는 뜻 |

## 1. 배경

원래 규칙은 "부채비율 200% 이하면 통과"였는데, 이걸 "85% 이하면 통과"로 강화하려는
시나리오. 모델을 다시 학습시키지 않고, 판정 방향을 딱 한 지점에서 밀어주는 것만으로
이 규칙 변경을 반영할 수 있는지가 실험 목표.

판정 방향(delta_v)은 L21(24단계 중 21번째)에서 계산했고, 이 문서의 모든 버전이 **같은
판정 방향을 재사용**한다 — 버전마다 다른 건 **판별기를 어떤 데이터로, 어떻게 학습시켰는가**다.

**중요한 규칙 하나**: 판정 방향과 판별기를 만들 때는 실제 평가용 데이터(test.csv,
38,160건)를 절대 쓰지 않는다. 오직 인위적으로 만든 데이터(합성 데이터)만 쓰고,
test.csv는 최종 성적을 매길 때 딱 한 번만 연다. 

## 2. 실험한 버전들

### v3a — 가우시안 + 보간 데이터로 학습

won의 모델 학습 방식(경계값 근처에 가우시안 분포로 데이터를 뿌리는 방식)과 똑같은
방법으로 "판별기 학습용" 데이터를 새로 만들고, 그걸로 판별기를 학습시켰다.

- 실데이터(test.csv) 표본 300건으로 판별기 정확도를 재보니 **85.2%**
- test.csv 38,160건 전체로 편집을 적용해 최종 채점: **정확도 95.4%, 반영률 70.1%, 보존율 98.0%**
- 특징: 보존율은 아주 높은데(안 바뀌어야 할 걸 잘 안 건드림) 반영률이 낮음(바뀌어야 할
  것도 놓치는 경우가 많음) — "조심스러운" 판별기

### v3b — 더 넓은 범위로 문맥을 흔든 데이터

v3a보다 훨씬 다양한 상황(다른 지표들이 안전한 범위 내에서 넓게 요동치는 문맥)에서
데이터를 만들어 판별기를 학습.

- 실데이터 판별기 정확도 **85.3%**
- 최종 채점: **정확도 91.0%, 반영률 89.1%, 보존율 80.2%**
- 특징: v3a와 정반대 — 반영률은 높은데(바뀌어야 할 걸 잘 잡음) 보존율이 낮음(안 바뀌어야
  할 것도 같이 건드림) — "과감한" 판별기

### v3b2 — v3b에 "노이즈" 섞어서 개선

v3b 방식에, 실제 데이터에서 흔히 보이는 패턴(다른 지표 1~2개도 같이 불안정한 경우)을
25% 정도 섞어서 다시 학습. "이 사람이 부채비율 구간에 있는가"만 판단하도록 라벨을
다시 정리한 게 핵심.

- 실데이터 판별기 정확도 **88.8%** (v3b보다 개선)
- 최종 채점: **정확도 95.1%, 반영률 87.1%, 보존율 91.5%**
- 특징: v3b의 "과감함"은 유지하면서 보존율 문제를 크게 줄임 — 지금까지 중 가장 균형 잡힌 단일 판별기

### v4 — 통합/조합 시도

v3a와 v3b2 둘을 재학습 없이 조합만 해서 더 나아지는지 시도.

- **통합 판별기(unified)**: v3a와 v3b2의 학습 데이터를 합쳐서 판별기 하나를 새로 학습.
  최종 채점: **정확도 96.4%, 반영률 84.7%, 보존율 95.6%**
- **확률 평균 앙상블(ensemble_prob_avg)**: 재학습 없이, v3a 판별기와 v3b2 판별기 각각의
  판단 확신도를 평균 내서 결정. 최종 채점: **정확도 97.0%, 반영률 83.6%, 보존율 97.7%**
  — 이 실험에서 나온 것 중 **정확도가 제일 높음**, 재학습도 필요 없어서 제일 간단.

## 3. 결과 비교표

| 버전 | 정확도 | 반영률 | 보존율 | 실데이터 판별기 정확도 |
|---|---|---|---|---|
| v3a | 95.4% | 70.1% | **98.0%** | 85.2% |
| v3b | 91.0% | **89.1%** | 80.2% | 85.3% |
| v3b2 | 95.1% | 87.1% | 91.5% | **88.8%** |
| 통합(unified) | 96.4% | 84.7% | 95.6% | — |
| **확률평균 앙상블** | **97.0%** | 83.6% | 97.7% | — |

(전부 test.csv 38,160건 기준. 판정 방향은 4개 버전 모두 동일한 L21 벡터 재사용.)


## 4. 결론

재학습 없이 순수 판정 방향 + 판별기 조합만으로 부채비율 규칙 편집이 가능함을 확인했다.
그중 **확률 평균 앙상블**(v3a+v3b2 판별기 확신도 평균)이 재학습 없이 가장 균형 잡힌
성적(정확도 97.0%)을 냈다.
