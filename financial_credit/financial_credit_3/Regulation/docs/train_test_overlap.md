# 학습 데이터 ↔ 시험 데이터 중복 실측 (train ↔ test overlap)

**결론**: 보간 학습셋에는 **시험 인스턴스(은행×기업 쌍)가 하나도 그대로 들어가지 않는다.**
학습행은 시험 행 두 개를 랜덤 볼록결합(α·A+(1−α)·B)해 만든 **새 합성행**이고, 예대율(%)은 따로
재샘플, 라벨은 규정(`check_rule_labels.py`)으로 재계산된다.

## 측정 방법 (재현)

`generate_train_interpolation.py`의 **기본값 그대로** 생성한 1,000,000행과 `test.csv`를 비교.

```bash
# 생성 (기본 입력 = data/test/text/test.csv, seed 42, 1,000,000행)
python src/dataset/generate_train_interpolation.py \
    --input_path data/test/text/test.csv --output_path <gen>.csv --num_rows 1000000 --seed 42
```

- 시험 데이터 `test.csv`: 38,232행 (보간 입력으로 쓰이는 12개 수치 feature가 완전한 행은 37,818개
  — 나머지는 비수치/결측이라 `load_source`의 `dropna`에서 제외됨).
- 생성 데이터: 1,000,000행.
- 비교 대상 컬럼:
  - **보간 12 컬럼**: 보통주자본비율(%), 기본자본비율(%), 총자본비율(%), 단순기본자본비율(%),
    공제후자본양수, 총자산순이익률ROA(%), 영업흑자, 이익잉여금양수, 부채비율(%), 유동비율(%),
    자기자본비율(%), 자본총계
  - **전체 13 feature**: 위 12개 + 예대율(%) (예대율은 보간하지 않고 N(100,8)에서 재샘플, 5%는 "산정불가")

## 1. 정확 일치 행 수

| 비교 기준 | 생성행 중 시험행과 완전 일치 | 비율 |
|---|---|---|
| **13 feature 전체 (예대율 포함)** | **0 / 1,000,000** | **0.0000%** |
| 보간 12 컬럼만 | 22 / 1,000,000 | 0.0022% |

- **전체 레코드가 시험행과 같은 경우는 0건** — 평가 인스턴스가 학습행으로 재현되지 않음.
- 12 컬럼만 일치한 22건은, 보간 시 두 소스 인덱스가 우연히 같게 뽑힌 경우
  (`first==second` → α와 무관하게 그 행의 12개 feature가 그대로 나옴, 기대값 ≈ 1e6/37,818 ≈ 26건).
  그러나 이 22건도 **예대율(%)이 독립 재샘플되어 13 feature 전체로는 시험행과 다르며**,
  bank/company ID는 합성(`bank_000xxxx`), 라벨은 규정 재계산값이다. → 평가행의 '복제'가 아님.

## 2. 최근접 거리 분포 (표준화 L2, 12 컬럼)

생성행 5,000개 무작위 표본 각각에 대해, 모든 시험행까지의 거리 중 최솟값
(각 feature를 시험셋 표준편차로 나눈 뒤 유클리드 거리):

| 백분위 | 0 | 1 | 5 | 25 | 50 | 75 | 95 | 99 | 100 |
|---|---|---|---|---|---|---|---|---|---|
| 최근접 거리 | 0.000 | 0.008 | 0.024 | 0.232 | 0.558 | 0.994 | 1.625 | 2.030 | 11.733 |

- 평균 0.674. 표본 5,000개 중 거리 0(=완전 일치)은 0건 (위 22건은 전체 1e6 중 극소수라 표본에 미포함).
- 분포가 0 근처에 몰리지 않고 중앙값 0.56로 넓게 퍼져 있음 → 대부분의 합성행은 어떤 시험행과도
  뚜렷이 다른 새로운 점.

## 3. 보간(볼록결합) 특성 확인

- 생성행의 12개 feature가 **전부(100.00%)** 시험 feature의 컬럼별 [min, max] 범위 안에 위치
  → α∈(0,1) 볼록결합으로 만들어진 내삽(in-distribution) 합성 데이터임이 일관됨.

## 요약

- **시험 인스턴스(13 feature 전체 레코드)를 학습에 사용하지 않음**: 정확 일치 0/1,000,000.
- 보간의 수학적 성질상 극소수(22건, 0.0022%)가 12개 feature에서 특정 시험행과 수치가 겹치나,
  예대율 재샘플·ID 합성·라벨 재계산으로 **동일 레코드는 존재하지 않음**.
- 입력 `test.csv`는 보류된 시험셋이 아니라 원천 재무데이터(`generate_test_csv.py`)에서 유도한
  **전수 bank×기업 쌍**이며, 보간은 그 분포에서 새 합성행을 만드는 용도로만 사용된다.
