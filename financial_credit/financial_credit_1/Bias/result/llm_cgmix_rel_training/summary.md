- v1(cgmix)과의 차이: gaussian 16,280행의 문맥을 **라벨별 4셀 25% 정확 균형**으로
  — (남,Husband,기혼)/(여,Wife,기혼)/(남,Not-in-family,비혼)/(여,Not-in-family,비혼).
  성별에 더해 **기혼 프록시(Husband/Wife)도 라벨과 독립**임을 가르침.

  relationship과 정합시켜 모순 문장 방지). 나머지 설정 v1과 동일.
- 모델: `outputs/finetuned_xlm-roberta-large_cgmix_rel/`

## 1. 실제 test (16,281) — 3개 모델 비교 (각 최종 epoch 3)

| | acc | DEO_repo | DEO_문헌 | TPR 남/여 |
|---|---|---|---|---|
| base | 0.8714 | 0.0976 | 0.0961 | 0.684 / 0.588 |
| cgmix v1 (sex 균형) | 0.8722 | 0.0993 | 0.0705 | 0.667 / 0.597 |
| **cgmix v2 (sex+rel 균형)** | **0.8734** | 0.0980 | **0.0594** | 0.670 / **0.610** |

- **acc 최고(0.8734) + DEO_문헌 최저(0.0594)** — 여성 TPR이 0.588→0.610으로
  단계적으로 오르고 남성은 유지. 목표(<0.05)까지 잔여 0.0094 —
  **자격 여성 약 6명분의 추가 승인**이면 도달.
- 에폭 추이(문헌 DEO): ep1 0.0953 → ep2 0.0844 → ep3 0.0594 (수렴 방향).
- DEO_repo(~0.098)는 세 모델 모두 불변 — 양성비율 구조 때문(분석 md 참고).

## 3. 묶음 스왑 프로브 — **과보정 발견 (중요)**

| (y=1에서) | v1 cgmix | v2 cgmix_rel |
|---|---|---|
| 예측 변화율 | 3.0% | **7.6%** |
| 여성→남성 취급 시 TPR | 0.597→0.598 (불변) | 0.610→**0.551 (하락)** |
| 남성→여성 취급 시 TPR | 0.667→0.683 | 0.670→**0.728 (상승)** |
| 성별 토큰 중립화 시 DEO(근사) | 0.072 | **0.102 (악화)** |

**해석**: v1은 성별 토큰에 불변이었지만, v2는 **여성 표지를 우대하는 토큰 경로가
새로 생겼다** (같은 사람을 여성으로 렌더링하면 승인이 늘어남). 4셀 균형 데이터가
"Wife도 Husband만큼 고소득"을 가르치는 과정에서, 실데이터의 구성 편향(비혼 여성
페널티)을 상쇄하는 방향으로 과보정된 것. 현재 DEO 0.0594는
[반여성 구성 편향] − [친여성 토큰 보정]의 순효과다.

**편집 설계에의 함의 (기회)**: v1에서는 "끊을 성별 경로가 없다"가 문제였는데,
v2에는 **증폭할 수 있는 친여성 토큰 경로가 존재**한다. locate로 이 경로(성별
표지가 판정에 기여하는 층/위치)를 찾아 **강화하는 방향의 편집**이 잔여 0.0094를
지우는 자연스러운 수단이 된다 — "정책: 성별 간 TPR 균등화"의 편집 실현.
단, 이 경로를 중립화하는 편집은 오히려 DEO를 0.10으로 악화시키므로 방향이 중요.
