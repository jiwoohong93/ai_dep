# cg-혼합 재학습 결과 (실데이터 + cg 경계 gaussian, 배치 2:1)

- base와의 차이: `data/train_cg_mix/text/cg_gaussian.csv` 16,280행을 추가하고
  배치 내 실:생성 = 2:1(RatioSampler)로 혼합. 나머지 설정 동일
  (XLM-R-large, lr 1e-5, batch 32, 3 epoch, seed 42, adult.data 32,561 전체).
- gaussian 데이터: cg ~ N(7000, 525) 양측 각 8,140행, label=(cg≥7000),
  문맥은 label-0 대표 프로필 고정, **sex만 라벨별 남:여 50:50 정확 균형**.
- 모델: `outputs/finetuned_xlm-roberta-large_cgmix/` (base 모델과 별도 보존)
- base 결과와의 비교 기준: [../llm_base_training/summary.md](../llm_base_training/summary.md)

## 1. 실제 test (16,281) — base 대비

| | acc | DEO_repo | DEO_문헌 |
|---|---|---|---|
| base (epoch 3) | 0.8714 | 0.0976 | 0.0961 |
| cgmix epoch 1 | 0.8653 | 0.1043 | 0.0692 |
| cgmix epoch 2 | 0.8722 | 0.1019 | **0.0626** |
| **cgmix epoch 3 (최종)** | **0.8722** | 0.0993 | 0.0705 |

- **정확도 손실 없음** (0.8714 → 0.8722): rule 데이터 혼합이 실분포 성능을
  해치지 않음 (Regulation 2:1 레시피 재현 성공).
- **DEO_문헌이 0.096 → 0.063~0.071로 내려감** (부수 효과): 성별 균형 gaussian
  데이터가 "동일 조건이면 성별 무관"이라는 신호를 준 것으로 보임.
  단 **목표(<0.05)에는 여전히 미달**이고 DEO_repo(~0.10)는 그대로 —
  대리변수 경로 편집(2번)의 필요성은 유지.

## 2. cg ≥ 7000 rule 학습 — 극적 개선

| 발동률 P(pred=1) | base ep3 | cgmix ep1 | cgmix ep2 | cgmix ep3 |
|---|---|---|---|---|
| fixed 문맥 경계 위 (기대 1) | 0.398 | **1.000** | **1.000** | **1.000** |
| fixed 문맥 경계 아래 (기대 0) | 0.231 | 0.000 | 0.000 | 0.000 |
| **random 문맥(OOD)** 경계 위 | 0.581 | **0.999** | 0.999 | 0.995 |
| random 문맥(OOD) 경계 아래 오발동 | 0.332 | 0.001 | 0.028 | 0.043 |
| 실제 test cg≥7000 (656행) | 0.991 | 0.995 | 0.995 | 0.995 |
| 실제 test 0<cg<7000 발동 (실제 라벨률 0.249) | 0.261 | 0.199 | 0.249 | 0.256 |

- fixed 경계셋 100%는 학습 분포와 같아 당연 (in-distribution 확인용).
- **random 문맥(held-out OOD)에서 발동 99.5%+, 오발동 ≤4%** — base의 58%/33%에서
  문맥-독립 임계규칙으로 확립됨. 학습에 없던 문맥 조합에서도 rule이 작동.
- 실데이터 행동도 보존: cg≥7000 발동 99.5%, 저구간 발동률은 실제 라벨률(0.249)과
  일치 (epoch 2~3).
