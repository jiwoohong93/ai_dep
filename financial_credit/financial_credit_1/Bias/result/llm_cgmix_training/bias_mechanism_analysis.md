# DEO 기제 분석 — 성별 스왑 프로브 + FN 여성 분해 (cgmix epoch 3)

분석 대상: `outputs/finetuned_xlm-roberta-large_cgmix/best` (실제 test 16,281,
acc 0.8722 / DEO_repo 0.0993 / DEO_문헌 0.0705). 원자료: `flip_probe_sex/`,
`flip_probe_sex_relationship/`, `epoch3/predictions.csv`.

## 1. 성별 스왑 프로브 — "성별 단어 때문인가?"

test 전 행에 대해 성별 표지만 바꾼 쌍둥이 문장으로 예측 비교:

| | sex 단독 스왑 | sex + Husband↔Wife 묶음 스왑 |
|---|---|---|
| 예측 변화율 (전체 / y=1) | 1.8% / 3.1% | 1.9% / 3.0% |
| 중립화 시 남는 DEO_문헌 (근사) | 0.037 | **0.072** |
| 자격(y=1) 여성을 남성 취급 시 TPR | 0.597→0.631 | 0.597→**0.598 (불변)** |

**판정: 모델은 일관된 성별 반사실(묶음 스왑)에 거의 불변 — 성별 표지 토큰은
판정에 사실상 기여하지 않는다.**

- sex 단독 스왑의 0.037은 "Male + Wife" 같은 학습 분포 밖 조합에서 나온
  아티팩트라 신뢰 불가 (묶음 스왑이 올바른 개입).
- 그런데도 DEO가 0.07인 이유: DEO의 두 항(TPR_남/TPR_여)은 **서로 다른 실제
  사람들**에 대한 평균이라, 함수가 성별-무시여도 **집단 간 입력 분포 차이**가
  출력 통계를 가른다. (예: "40시간 이상이면 승인" 규칙만 있어도, 40시간 이상
  비율이 남녀 다르면 DEO≠0.)

## 2. 목표의 산술 — DEO_문헌 < 0.05가 요구하는 것

TPR_남 0.667 − TPR_여 0.597 = 0.070 → 0.05 미만으로 좁히려면
(남성 고정 시) 여성 TPR을 0.617 이상으로: **y=1 여성 590명 중 거절된 238명에서
약 12명 이상을 추가 승인**하면 도달. 단 편집은 영역 단위 개입이라 주변 y=0
여성의 오승인(정확도 하락 ≤1%p 제약)과의 트레이드오프가 본질.

## 3. FN 여성 분해 — 어떤 변수가 거절을 만들었나

거절된 자격 여성(FN) 238명 vs 승인된 자격 여성(TP) 352명:

| 변수 | FN | TP | 관여 |
|---|---|---|---|
| relationship=Wife | 38% | 73% | **최대 — 기혼이면 승인 쪽** |
| marital 비혼 계열(Divorced/Never-married/Unmarried) | ~59% | ~26% | **비혼 페널티** |
| capital-gain > 0 | **0%** | 38% | 자본 신호 있으면 구제 (주입한 cg rule 포함) |
| education=HS-grad | 26% | 12% | 고졸 불리 |
| occupation Exec/Prof | 44% | 66% | 전문·관리직 유리 |
| 근로시간·나이 (중앙값) | 40h/41세 | 40h/41세 | 관여 없음 |

여성 y=1 내 승인/거절 분류 트리(acc 0.89) 중요도:
capital-gain 0.32 > relationship 0.30 > education-num 0.21 > capital-loss 0.17.

## 4. 혼인 × 성별 교차 — 격차의 구조

| y=1 TPR | 여성 | 남성 |
|---|---|---|
| 기혼(Married-civ-spouse) | **0.728** | 0.685 |
| 비혼 | **0.395** | 0.502 |
| 비혼 구성비 | 39% | 10% |

- **구성 효과가 주범**: 모델의 "기혼=고소득" 프록시 + 자격 여성의 비혼 비율이
  남성의 4배 → 여성 평균 TPR 하락. 기혼끼리는 여성이 오히려 높음.
- 비혼 내 잔여 격차(여 0.395 vs 남 0.502)도 성별 토큰이 아니라 비혼 여성에 흔한
  직업 구성(Adm-clerical 등)을 경유.
- 참고 — relationship 값과 성별은 사실상 결정 관계: Husband(남 13,192/여 1,
  P₁=0.449), Wife(여 1,566/남 2, P₁=0.475), 나머지 4개 값은 P₁ 0.01~0.10.
  여성 비혼은 Unmarried(여 2,654/남 792, P₁=0.063)에 집중.

## 5. 편집 시나리오 1차 결론

1. "성별 경로 차단"형 편집은 무효 (이미 불변) — **TPR을 직접 겨냥한 개입** 필요.
2. 최대 레버리지 타깃: **비혼 자격 여성 233명 (TPR 0.395, FN의 141명)** —
   "비혼+자본신호 없음+전문직/고학력" 영역의 판정 완화가 서사·산술 모두 성립.
3. DEO_repo(<0.05)는 남녀 양성비율 차이 때문에 구조적으로 어려움(성별-불변인
   KAIST 재학습 모델도 0.086~0.122) → **DEO_문헌을 1차 목표로 권고.**

## 6. relationship 중립화 프로브 — 전면 개입은 실패

`src/models/probe_neutral_relationship.py`: test 전 행의 relationship/marital을
동일 값으로 통일해 "기혼 신호가 사라진 세계"를 시뮬레이션
(`result/llm_cgmix_rel_training/neutral_relationship_{unmarried,married}/`).

| (원본: acc 0.8734 / DEO_문헌 0.0594) | 전원 비혼 취급 | 전원 기혼 취급 |
|---|---|---|
| accuracy | 0.8431 (−3.0%p) | 0.7958 (−7.8%p) |
| TPR 남 / 여 | 0.366 / 0.312 | 0.699 / 0.815 |
| DEO_문헌 | 0.0545 (−0.005뿐) | 0.1162 (역방향 악화) |

- 기혼 보너스 제거: 남녀 TPR 동반 폭락, **격차는 거의 그대로** — 격차가 다른
  상관 feature로도 흐르고 있고, 모델의 승인 능력이 기혼 신호에 크게 의존.
- 전원 기혼 취급: v2의 여성-기혼 우대가 전면 발동, 격차 역전 + acc 붕괴.
- → relationship 신호의 **제거/치환형 개입은 배제**. 국소·표적 개입만 유효.

## 7. 비혼 디메리트의 실체 — 구간별 캘리브레이션 불균형 (남녀 공통, 여성 더 심함)

precision(승인 중 실제 고소득 비율)과 recall(자격자 커버)을 혼인×성별로 분해:

| | precision | recall (자격자) | 기혼 대비 recall 낙차 |
|---|---|---|---|
| 기혼-남성 | 0.765 | 0.689 | — |
| 기혼-여성 | 0.751 | 0.768 | — |
| 비혼-남성 | 0.837 | 0.495 | −0.194 |
| **비혼-여성** | **0.887** | **0.369** | **−0.399** |

- **비혼 디메리트는 남녀 공통**: 같은 성별 안에서도 비혼이면 recall이 급락하고
  precision이 상승(= 더 확실할 때만 승인 = 실질 문턱이 더 엄격).
- 전부 부당한 것은 아님 — 비혼 기저율(0.062)이 기혼(0.445)보다 낮아 신중함
  자체는 근거가 있음. **문제는 정도**: 일관된 확신 기준이면 구간별 precision이
  비슷해야 하는데 비혼(0.854)이 기혼(0.763)보다 확연히 높음 = 과소승인.
- 그 "필요 이상" 부분이 여성에 더 쏠림: 낙차 2배, precision 최고(0.887).

## 8. 최종 편집 전략 — 두 안의 근거 비교와 확정

| | 1안: 비혼 페널티 완화 (확정) | 2안: 친여성 토큰 경로 증폭 (예비) |
|---|---|---|
| 근거 | **데이터 기반** — §7의 구간별 문턱 불균형 실측 (캘리브레이션 교정) | 정책 요구뿐 (데이터 근거 없음) |
| 절차 공정성 | **성별-중립** (혼인 상태에만 조건화) | 성별 조건화 (KAIST 2.94/1.52 가중과 동류의 결과-보정) |
| DEO 달성 산술 | 비혼 recall을 남녀 공통 δ만큼 올리면 격차가 0.29δ 감소 (여성 자격자의 39%가 비혼 vs 남성 10%) → **δ≈3.3%p면 <0.05** | 스왑 실측상 경로 강도 ~+0.06 TPR — 소폭 증폭으로 잔여 0.0094 커버 가능 |
| 부작용 한도 | precision 여유(0.854)에서 지불 — acc 하락 ≤1%p 제약 내 관리 | 절차 편향 심화 (스왑 불변성 악화) |

**확정 목표**: locate로 **capital-gain(rule)이 반응하지 않으면서 비혼 표지
(Not-in-family / Never-married / Unmarried)가 반응하는 내부 위치**를 찾고,
그 위치의 판정 기여를 완화하는 편집으로 비혼 recall을 남녀 공통 ~3.3%p 인상
→ DEO_문헌 <0.05, acc 하락 ≤1%p, cg rule 무손상(위치 분리로 보장)을 동시 달성.
